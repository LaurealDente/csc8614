FAQ

Who is eligible?
Flavortown is for high schoolers! You need to be 13-18 years old to participate.

How much does it cost?
100% free - all the prizes are donated to us or paid for by us!

What types of projects count?
All kinds of technical projects as long as it's open-source!

What if I'm over 18?
If you're 19 or older, you can earn all the same prizes by referring teens ages 13-18. Learn more. ( https://hack.club/flavortown-ghe-referral-guide )

About GitHub x Hack Club
Since 2018, GitHub has teamed up with Hack Club ( https://hack.club/flavortown-ghe-hackclub ) to support high schoolers building awesome open source projects!
Hack Club is a nonprofit that gives away over $1M/year to teens ages 13-18 for their coding and electronics projects.
They also run awesome hackathons like the upcoming Hack Club Campfire ( https://hack.club/flavortown-ghe-campfire ) (Feb 2026) in 200 cities!
